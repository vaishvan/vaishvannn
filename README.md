# Vaishnav's Portfolio

A Persona 3 themed portfolio built with React and Vite.

Live site: https://vaishvan.github.io/vaishvannn/

## Reference

This site is based on [wal-z1/persona3-portfolio](https://github.com/wal-z1/persona3-portfolio), customised with my own content, layout tweaks and GitHub Pages deployment. Typography follows [MdHussain121/Persona3_themed_website](https://github.com/MdHussain121/Persona3_themed_website).

Persona 3 artwork and assets belong to ATLUS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173/vaishvannn/.

## Deploy

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes `dist` to the `gh-pages` branch.
